## 购买前需要确认的几件事

### 1. Softbank线路不等于固定回程

实际网络路径可能随访问地区和运营商变化。购买后应测试：

- 中国电信
- 中国联通
- 中国移动
- 日本本地宽带
- 移动网络
- 目标用户所在地区

不要把单次测速结果当成长期保证。

### 2. 价格可能因计费周期变化

官方页面同时提供月付、季付、半年付和年付，但不同配置默认展示的周期不同。结账时应确认：

- 实际账单周期
- 续费价格
- 是否有一次性费用
- 套餐是否仍有库存
- 所选数据中心是否确实为 JPOS_1
- 购买后是否可以迁移

### 3. 这是自主管理服务

你需要自己负责 SSH 安全、密钥登录、防火墙、系统更新、应用备份和监控。建议至少完成以下基础设置：

1. 禁用密码登录，改用 SSH 密钥。
2. 修改默认 SSH 端口或配合防火墙限制来源。
3. 配置自动安全更新。
4. 设置磁盘和内存监控。
5. 将重要数据备份到独立位置。
6. 不要把唯一一份数据库备份放在同一台 VPS 上。

### 4. 不要只看端口速度

2.5 Gbps、5 Gbps 或 10 Gbps 是端口上限，不代表你的应用一定能跑到对应速度。实际吞吐还会受 CPU、磁盘、连接数、协议、对端服务器和网络路径影响。
